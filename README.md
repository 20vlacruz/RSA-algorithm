# 🔐 RSA Algorithm

## 🏴󠁥󠁳󠁣󠁴󠁿 Català

### 📌 Descripció  
Aquest projecte implementa l’algorisme **RSA** per a xifrar i desxifrar dades.  
El repositori inclou tant el codi font com una versió compilada de l’aplicació.  

### 📥 Descàrrega  
Pots descarregar l’aplicació directament des de la carpeta [`dist`](./dist):  
👉 [Descarrega aquí la versió compilada](https://github.com/20vlacruz/RSA-algorithm/raw/main/dist/Algorisme%20RSA%20Victor%20Lacruz.exe)  

### ▶️ Execució  
1. Descarrega l’arxiu des del link anterior.  
2. Fes doble clic sobre **Algorisme RSA Victor Lacruz.exe** per executar-lo a Windows.  
3. Si el sistema et demana permís de seguretat, accepta l’execució.

## 🇬🇧 English

### 📌 Description  
This project implements the **RSA** algorithm for encrypting and decrypting data.  
The repository includes both the source code and a compiled version of the application.  

### 📥 Download  
You can download the application directly from the [`dist`](./dist) folder:  
👉 [Download the compiled version here](https://github.com/20vlacruz/RSA-algorithm/raw/main/dist/Algorisme%20RSA%20Victor%20Lacruz.exe)  

### ▶️ Run  
1. Download the file from the link above.  
2. Double-click **Algorisme RSA Victor Lacruz.exe** to run it on Windows.  
3. If the system asks for a security confirmation, allow the execution.
